一个零依赖的缠论（缠中说禅）交易分析工作站：四个市场的免费实时行情 + 服务端实时计算的缠论结构（分型 / 笔 / 线段 / 中枢 / 走势类型 / 背驰 / 三类买卖点 / 区间套）+ 干支六爻算卦择时。

- 前端：原生 HTML + CSS + Canvas，无框架、无构建步骤
- 主题：深色 / 浅色双主题可切换（右上角 ☀/☾ 按钮或 Ctrl/⌘ + J），图表配色随主题自适应
- 后端：Node.js（≥18）原生 `http`，**不依赖任何 npm 包**
- 行情：全部使用公开免费接口，多源组合 + 自动降级
- 覆盖：A股、港股、美股、加密货币

## 快速启动

```bash
cd /home/node/default/chanlun-station
./start.sh            # 或 PORT=8931 node server/index.js
# 打开 http://127.0.0.1:8931/
```

## 主题切换

- 右上角 **☀ / ☾** 按钮，或快捷键 **Ctrl/⌘ + J**；
- 选择写入 `localStorage`（键 `chan-theme`），刷新后保持；
- 也可用 URL 参数直接指定：`/?theme=light#structure`、`/?theme=dark#overview`（同时会被记住）；
- 全部颜色走 CSS 变量（`--bg / --panel-a / --line / --up / --down / --gold / --candle-up …`），Canvas 图表在每次绘制时从 CSS 变量读取调色板，因此两个主题下 K 线、笔、线段、中枢、买卖点、MACD 都会自动换色。

### 理论页弹窗与深链

理论页的每一条（概念 / 问答 / 课段 / 实战流程）都是「卡片入口 + 弹窗详情」，不做内联下拉展开：

- 点击卡片弹出详情弹窗，`←` `→` 在同一列表内翻页，`Esc` / 点遮罩 / 右上 ✕ 关闭；
- 「关联概念」标签可直接跳到对应概念的弹窗；
- 弹窗右下「在结构图上找它 →」跳到结构分析页用当前标的验证；
- 深链：`#theory?tab=questions` 直达某个子页签，`?tx=中枢` 直接打开某条详情（也方便分享给朋友）。

## 缠论引擎（`server/lib/chan.js`）

处理链：

```
原始K线 → 包含处理 → 分型 → 笔(≥5根合并K线) → 线段(3笔分型法)
        → 笔中枢(三笔重叠, ZG=min高 / ZD=max低, 九笔升级标记)
        → 走势类型(中枢依次抬高/降低→趋势, 重叠→盘整)
        → 背驰(MACD 红绿柱面积 + DIF 极值, 同向两段比较)
        → 一类点(背驰终点) / 二类点(一买后回抽不破前低) / 三类点(回抽不回中枢)
        → 区间套(多级别摘要 + 共振判定)
```

**如实标注的简化**（源码注释与页面提示一致）：

1. 线段采用「笔的分型法」近似划分（把笔当 K 线做包含处理 + 分型），未做严格特征序列的缺口二次确认；
2. 中枢以笔中枢为主，线段中枢仅作升级提示；
3. 背驰用 MACD 面积比 < 0.92（段级）/ < 0.85（笔级）+ 价格创新极值的数值化近似。

| 页面 | 刷新内容 | 频率 |

## 理论 → 图上标注（教学标注）

理论库的每条详情弹窗右下角都有「**在结构图上标注它 →**」，点它会跳到结构分析页，并针对该概念在图上直接画出对应结构：

| 概念 | 图上的标注 |
| --- | --- |
| 分型 / 笔 | 最近 3–4 笔的色带 + 每个端点的「顶分型 / 底分型」气泡与价格 |
| 线段 | 最近 3 条线段的紫色色带、方向与完成状态 |
| 中枢 | 中枢矩形高亮 + ZG/ZD 虚线（右侧标注具体数值）+ 笔数/升级提示 |
| a+A+b | **a 进入段、A 中枢、b 离开段** 三段分色 + ZG/ZD + a/b 的 MACD 面积比 |
| 趋势背驰 / 盘整背驰 | 前一段 vs 背驰段两段对比 + 极值气泡 + 面积比结论 |
| 一/二/三类买点 | 背驰段或中枢 + 回抽段 + 买点气泡 + 止损参考线 |
| 中枢扩展 / 中阴 / 同级别分解 … | 当前中枢 + 当前笔端点高亮，配对应判读要点 |

- 标注时**区间外会压暗**，焦点只在被标注的那几段；图表自动缩放到该结构。
- 顶部「教学标注」卡片会列出 **3–5 条图上要点**，全部用当前图上的真实日期、价格、MACD 面积、笔数写出（不是模板话术）。
- 结构页右上新增「**教学标注**」下拉，可随时切换/关闭；URL 带 `hl=` 可直接分享，例如 `?m=A&c=600519&p=day&hl=a_A_b#structure`。
- 面板底部可一键换级别（日线/60 分/30 分…）对同一概念重新标注——这正是「级别」「区间套」最好的直观演示。

## 算卦取数规则（可复现）

起卦数 = 四柱支序 + 标的哈希 + 现价档 + 涨跌基点 + 占次，混合成一个「摇卦数」后取模：

```
摇卦数 R = FNV1a( 市场:代码 | 价格档 | 涨跌基点 | 四柱支序 | 占次 )
上卦 = (四柱支序 + R % 97) % 8 || 8
下卦 = (四柱支序 + (R>>8) % 89 + 时支序) % 8 || 8
动爻 = (四柱支序 + (R>>16) % 7) % 6 || 6
```

- **随市模式（默认）**：`NVDA`、`BTCUSDT` 这类字母代码也各有其卦；点一次「起卦」占次 +1，**必得新卦**；价格每变动约 1%（量级分档，如茅台 10 元一档、BTC 100 一档）也会换卦；开「实时跟随」每 12 秒按最新行情重取。
- **时辰模式**：只吃「标的 + 四柱」，同一时辰内同一标的固定一卦，用于「一卦问一事」。
- 页面左下「本次取数依据」把四柱支序、标的哈希、摇卦数、价格档（含换档区间）、涨跌基点、占次、实时报价逐项列出，结果可复现、可解释。
- 输入框自动识别市场：`600519`→A股、`00700`→港股、`NVDA`→美股、`BTCUSDT`→加密；也支持 `sh600519` 这类带前缀写法。
- 其它交互：右上「另起一卦」、`Enter` 直接起卦、`?code=NVDA&mode=price` 深链直达、卦象变化时弹「卦变：旧卦 → 新卦」提示、左下「最近起卦」保留最近 6 次。

## 数据源矩阵

| 市场 | 日/周/月 | 分钟线 | 实时报价 |
| --- | --- | --- | --- |
| A股 | 腾讯 `ifzq.gtimg.cn` 前复权 → 东财 → 新浪 `scale=240` 兜底 | 新浪 `CN_MarketDataService`(1/5/15/30/60) → 腾讯 `mkline` → 东财 | 腾讯 `qt.gtimg.cn` |
| 港股 | 腾讯 `fqkline` → 东财 | 暂缺（页面自动隐藏分钟级别） | 腾讯 |
| 美股 | 纳斯达克官方 `api.nasdaq.com` → 新浪美股日线 → 东财；周/月由日线聚合 | 暂缺 | 腾讯 |
| 加密 | 币安 `data-api.binance.vision` klines | 币安 1m/5m/15m/30m/1h/4h | 币安 ticker/24hr |

> 说明：`web.ifzq.gtimg.cn` 带风控会返回 501，故统一走 `ifzq.gtimg.cn` 与 `proxy.finance.qq.com` 两个入口；所有外部请求带超时、重试、并发去重与 TTL 缓存（报价 4s / 日线 60s / 分钟线 20s / 雷达 90s）。
