# 缠论工作站 · Chan Structure Workstation

A deterministic, dependency-free Chan-theory (缠论) structure engine with a full
trading workstation: A-shares · HK · US · crypto, teaching annotations, mobile PWA
and an (entertainment-only) I Ching timing module.

- **Structure engine** — inclusion merging → fractals → strokes → segments → pivots →
  divergence → 1st/2nd/3rd class buy/sell points. Pure functions, 22 unit tests.
- **Explainability** — every concept can be highlighted on the chart with the real
  dates, prices and MACD areas that produced it.
- **Multi-market** — free data adapters with fallback chains, no API keys.
